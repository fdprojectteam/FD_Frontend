# Goal-Based FD Booking — Problem Statement

## Problem

Customers typically know their financial goal or required amount,
but may not know which FD product, tenure, or investment amount
is appropriate.

The current marketplace primarily presents FD products and their
attributes.

The new experience should begin with the customer's goal and
guide them toward a suitable FD configuration.

## Objective

Allow a customer to:

Goal
→ Understand requirement
→ Receive rule-based recommendation
→ Select FD
→ Configure investment
→ Complete booking

## POC Approach

The POC will use deterministic rule-based recommendations.

No real AI decision-making is required in this phase.

## Success Criteria

A customer should be able to complete a goal-based FD booking
without manually evaluating every FD product.
