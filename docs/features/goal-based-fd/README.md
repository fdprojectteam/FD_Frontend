# Goal-Based FD Booking — POC

## Objective

Build a recommendation-led FD experience where the customer
starts with a financial goal, provides relevant inputs, receives
an explainable FD recommendation, and proceeds to the existing
FD booking journey.

## POC Approach

Rule-based recommendation only.

AI/ML is not part of this POC.

## Supported Scenarios

1. Senior Citizen FD Investment
2. Multi-Goal FD Allocation
3. Target Maturity Amount in 5 Years

## Existing System Reused

Goal-Based Layer
        ↓
Existing FD Domain
        ↓
Existing Marketplace
        ↓
Existing Booking

## POC Does NOT Include

- AI/ML/LLM
- Live bank APIs
- Real-time rate feeds
- Production rate infrastructure
- Complete wealth-management platform
- Rebuilding FD domain
- Rebuilding Marketplace
- Rebuilding Booking
