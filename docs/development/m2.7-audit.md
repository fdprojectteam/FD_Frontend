## 12. Phase 3 handover — the Comparison module only

- **`/compare` is URL-authoritative.** Anything that navigates there composes
  `?ids=` through `compareHref`. Booking must not assume the store.
- **`CompareActionBar`'s Proceed is inert by decision** (D3/D-A5). What crosses
  into booking is a Phase 3 decision; the bar is ready to receive `onProceed`
  and must not acquire the authority to decide it.
- **The cap has one owner.** Any new selection surface calls the store's
  `add`/`toggle`; on `/compare` it writes the URL instead.
- **The row model has one call site.** A new presentation consumes
  `buildCompareRows`' output; it does not rebuild it.

**No file under `src/` and no file under `verification/` was modified by this
audit.**
