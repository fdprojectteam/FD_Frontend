## Verification

Structural rows (A1–A5, B1–B7, D1–D5) are assertable by the existing harness —
static probes for the token, the utility, the container classes, heading
structure, and the zero-writer rule; journey assertions for C1–C7.

Rows describing **breakpoint-dependent rendering** (E1–E5, E8) are **not**
verifiable in jsdom, which has no layout engine: it will not tell us that a grid
is 4-up at 1280 px and 2-up at 375 px. Those require a real browser or a visual
pass, and this is the same limitation recorded as M2.4 risk R8. Stating it now
so "all green" is not mistaken for "pixel-verified".
